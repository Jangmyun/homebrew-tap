# Jangmyun/homebrew-tap

Homebrew formulae for [Ferrika](https://github.com/Jangmyun/ferrika), a
single-binary Kafka command-line client.

```bash
brew install jangmyun/tap/ferrika
```

or `brew tap jangmyun/tap` and then `brew install ferrika`.

The formulae are generated by the Ferrika release workflow; changes go to the
[ferrika](https://github.com/Jangmyun/ferrika) repository, not here.
